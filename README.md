This is a in-development HEIC converter for the Windows OS.
Used Claude to resolve issues with the file system and pushing to Github.
Other than that, it's currently terminal based and the UI will be created off of React and TS.
A drag and drop feature will be used and multi-file support will come soon...
For now, you can use it in terminal, make sure the .heic file is in either the DESKTOP, DOWNLOADS, or ONEDRIVE directories
It should make a completely new file of that file in the specified format of PNG, JPG, or WEBP.

Yeah, That's all for now. ENJOY!!
